GitHubアップロード用：トリヨ音声入力 Android試作プロジェクト

このフォルダ内のファイルとフォルダをすべてGitHubリポジトリの最上位へアップロードしてください。
.github フォルダも含めてください。

アップロード後、Actionsタブで「Build Android APK」を実行すると、成功時に
toriyo-voice-debug-apk という成果物（Artifact）に app-debug.apk が保存されます。

注意：これは試作版です。Android標準音声認識、編集、TXT/DOCXの試作保存、録音、ChatGPTへの共有を含みます。
AI修正の自動取り込み、録音ファイルの共有保存、長時間連続認識の安定化、実機検証は今後の課題です。
debug APKはテスト用であり、Google Play公開用の正式署名版ではありません。
